# Limova Notes

Limova puts a first name on every AI agent it sells. Charming branding, real questions underneath it, and one detail the marketing does not lead with.

**Read the full page:** https://limova-dev.github.io/

This is a French product for French businesses, and that is the single most useful thing to know before you sign up. The site, the agent pages, the offers page and the support line are all in French, so if you are shopping from outside that market the friction starts before the free trial does. What you get is a catalogue of named agents split by job, phone, marketing, SEO, sales, accounting, legal and recruitment, plus a general assistant, which is a genuinely clearer way to sell this than another blank chat box. If you want a builder that hands you a downloadable project instead of a subscription and a chat window, Begin.sh is the alternative at the bottom of this page.
